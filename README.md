# Holdings

A simple, private net-worth tracker. Add your assets and debts, group them by category, and see your net worth at a glance.

- **No account, no server.** Everything is saved in your browser's local storage.
- **Export / Import** a JSON backup to move your data between devices.
- **Multi-currency display** (USD, EUR, GBP, CAD, AUD, JPY, CHF, INR).

## Run it on GitHub Pages

1. Push this repo to GitHub.
2. Go to **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
4. After a minute, the app will be live at `https://<your-username>.github.io/<repo-name>/`.

## Run it locally

Open `index.html` in any browser. There's nothing to install.
